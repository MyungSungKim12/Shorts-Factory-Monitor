# Shorts Factory 대시보드 (프론트엔드)

파이프라인 실행 상태·업로드 영상·성과 리포트를 보여주는 관리 대시보드.
백엔드(`D:\ms\shorts-factory-be`, 포트 8000)와 `/api` 프록시로 통신한다.

## 실행

```bash
npm install
npm run dev   # http://localhost:5173
```

## 구성
- `src/App.jsx` — 파이프라인 상태 / 에이전트 목록 / 성과 리포트 3개 카드
- 백엔드 미기동 시 "백엔드 연결 실패"가 표시됨 (정상 동작)

## 회차별 소재 예약 사용법

오늘과 내일의 네 회차가 카드로 표시된다. 모든 시각은 KST 기준이다.

| 회차 | 소재 입력 마감 | 업로드 |
|------|----------------|--------|
| 1 | 09:00 | 11:00 |
| 2 | 12:00 | 14:00 |
| 3 | 15:00 | 17:00 |
| 4 | 19:00 | 21:00 |

1. **관리자 토큰**에 백엔드 `.env`의 `DASHBOARD_TOKEN`을 입력한다. 토큰은 현재 브라우저 탭의 `sessionStorage`에만 저장되며 탭 세션이 끝나면 다시 입력해야 한다. 토큰이 없어도 조회는 가능하지만 소재 확인·예약·승인·반려 같은 변경 작업은 `401`로 거절된다.
2. 입력 마감 전 소재와 선택 조건을 작성하고 **소재 확인**을 누른다. 모호하면 제시된 해석을 선택해 다시 검사하고, `reservable` 결과의 검증 방식과 미디어 가능성을 확인한다.
3. **이 소재 예약**을 눌러 `reserved` 상태를 확인한다. 마감 시각에 제작이 시작되고 `review_ready`가 되면 영상, 메타데이터와 QC 결과를 검토한다.
4. 업로드 시각 전에 승인하면 정시에 업로드한다. 정시가 지났거나 `held` 상태인 영상을 승인하면 즉시 업로드 작업을 시작한다. 승인 전에는 자동 대체 영상이나 YouTube 업로드가 발생하지 않는다.
5. 반려 시 이유를 입력한다. 결과물은 서버의 반려 보관소에 기본 7일 보존되며, 마감 전에는 새 소재를 다시 입력할 수 있다. 실패·반려 상태에서는 같은 소재 재시도, 새 소재 재검사 또는 건너뛰기를 선택한다.

제작 전에 자동 운영으로 되돌리려면 **수동 예약 취소**를 누른다. 완료 후 새로고침하면 카드가 `auto`로 돌아가고 기존 자동 제작·업로드 경로를 사용한다. `locked` 이후이거나 입력 마감이 지난 회차는 취소할 수 없다.

작업 실패 시 진행 로그에서 실패 단계를 확인한다. 활성 작업자가 종료된 뒤에만 재시도하며, 각 시도는 이전 반려 산출물을 덮어쓰지 않고 별도 attempt로 기록된다. 승인되지 않은 수동 영상은 업로드되지 않는다.
